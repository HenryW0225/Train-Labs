❓ How to Use Train Labs

🧩 Building AI Programs

Click any block in the left panel to add it to the workspace. Drag blocks to reposition them. Blocks snap together to form a program stack that runs top to bottom.

▶ Running Your AI

Press the green Run button (or press Space) to execute your block program. Watch the AI Stage on the right for results, charts, and your robot's reactions!

🔗 Connecting Blocks

Drag a block close to the bottom of another block — it will snap together to form a sequence. The green glow shows where it will connect!

🏆 Earning XP & Badges

Every block you use and every mission you complete earns XP. Level up to unlock bragging rights and feel awesome about learning AI!

🗂️ Block Categories

  • 🟣 Data & Datasets — Load and prepare data
  • 🔵 Machine Learning — KNN, Decision Trees, Logistic Regression, K-Means, Regression
  • 🟢 Neural Networks — Build deep learning models with TF.js
  • 🟡 Computer Vision — Classify and analyze images
  • 🟠 Natural Language — Sentiment, tokenize, spam detection
  • 🔴 Reinforcement Learning — Train agents in grid worlds
  • ⚙️ Logic & Control — Loops, variables, conditions
  • 🩵 Output & Viz — Charts, messages, celebrations!

⌨️ Keyboard Shortcuts

  • Space / Enter — Run program
  • Escape — Stop execution
